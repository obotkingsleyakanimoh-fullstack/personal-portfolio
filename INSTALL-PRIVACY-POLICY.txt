INSTALL
1. Back up your current src/pages/Pages.tsx.
2. Replace it with the file in this patch. It contains the expanded privacy policy and adds a visible Privacy Policy + Terms link to the homepage.
3. Do not rerun database migrations; this is a frontend policy-content update only.
4. Run: npm ci
5. Run: npm run build
6. Commit and push the change so Cloudflare deploys it.
